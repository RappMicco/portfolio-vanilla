# ✨ Faith Lift

> "Uplifting words for a weary heart"

Faith Lift is a simple **CLI application** that allows users to register, log in, manage user data, and receive uplifting Bible verses based on their emotions.

Created by **Rapp Micco Rizo**  
Uplift Code Camp - Batch 28 (Momentum)

---

## 🚀 Features

### 🔐 Authentication
- User Registration
- User Login
- Basic credential validation

### 👥 User Management (CRUD)
- View all users
- Update user details
- Delete user records

### 💖 Faith & Encouragement System
- Interactive emotional flow
- Displays Bible verses based on user feelings
- Positive and negative emotion support

### 🖥️ CLI Interface
- Built using Node.js `readline`
- Menu-driven navigation
- Simple and interactive console UI

---

## 🛠️ Tech Stack

- JavaScript (ES6)
- `readline` module
